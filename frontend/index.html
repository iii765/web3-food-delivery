🛵 Web3 外卖平台

本地联调统一入口。按角色打开页面、切换 MetaMask 账户，完成一笔订单的全流程测试。

本地网络：Hardhat Local（31337） 合约：加载中…
🙋
用户端
下单、查看订单、确认收货或取消待接单订单。
 🏪
商家端
查看分配给自己的订单并接单。
 🛵
骑手端
抢已接订单，并在配送后确认送达。
 🛠️
管理端
查看订单总览、协议费用和链上事件。
唯一测试顺序：
1. 终端 A：npm run node
2. 终端 B：npm run deploy:local（自动同步最新地址）
3. 用户端下单 → 商家端接单 → 骑手端抢单/送达 → 用户端确认收货 → 管理端核对分账

本地链重启会清空订单和合约；每次重启后都必须重新执行 npm run deploy:local，再刷新页面。
